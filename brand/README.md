# RecoVault Brand Kit

This package is designed for direct use by Claude Code.

## Feed Claude these first
- `RECOVAULT_BRAND_GUIDE.md` — visual/UX source of truth
- `BRAND_TOKENS.json` — machine-readable design tokens
- `CLAUDE_BRAND_IMPLEMENTATION.md` — implementation instruction

## Assets
The `assets/` folder contains the logo images already generated in this conversation where available.

Do not ask Claude to redesign the brand. Ask it to implement the supplied system within the currently permitted engineering milestone.
