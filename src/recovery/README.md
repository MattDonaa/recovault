# src/recovery — Deterministic Recovery Rules

Deterministic, rule-based detectors and confidence scoring. No ML, no LLM
involvement in liability, anomaly existence, recovery amount, or eligibility.

Planned rule families (activated only in their milestones):
- MR-001 — Inbound Shipment Discrepancy
- MR-002 — Return Financial / Outcome Mismatch
- MR-003 — Stock-Loss Event Without Matching Recovery

Empty at Milestone 01 (foundation only). Populated in later milestones.
