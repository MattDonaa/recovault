# src/core — Marketplace-Agnostic Core

Home of the marketplace-agnostic domain (`marketplace-recovery`): source-record
preservation, the normalized event ledger, the deterministic recovery engine,
candidates, cases, evidence, and recovery matching.

Core code depends only on the generic `MarketplaceAdapter` contract — never on
Takealot-specific DTOs, auth, or schemas.

Empty at Milestone 01 (foundation only). Populated in later milestones.
